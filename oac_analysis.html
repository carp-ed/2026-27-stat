Variance of the 3 PC marks of each skater

分析裁判對同一位選手的「三項分數差 (Max - Min)」。若差值 ≤ 0.25，將標記為紅色 (警示未拉開分數/Halo Effect)；差值 ≥ 1.00，標記為綠色。

Range of marks for the whole segment

分析裁判在「整場比賽所有選手」中給出的最低與最高 PCS (三項合併看)。區間差 ≤ 1.50 將給予紅色警示 (Corridor Judging)。

Composition / Presentation / Skills : Range

Number of times a judge has given a certain mark

依序呈現三項分數及總分的給分次數。表格底部統計裁判「使用了幾種不同的分數 (Distinct Marks)」。
